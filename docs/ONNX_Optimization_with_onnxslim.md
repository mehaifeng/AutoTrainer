# ONNX 模型优化 - onnxslim

## 概述

本软件使用 `onnxslim` 进行 ONNX 模型优化，替代传统的 `onnxsim`。

## 为什么选择 onnxslim？

### 性能对比

| 工具 | 优化速度 | 模型精度 | 压缩率 | 兼容性 |
|------|---------|---------|--------|--------|
| **onnxslim** | ⚡ 快 | ✅ 高 | 📦 好 | ✅ 优秀 |
| onnxsim | 中等 | 良好 | 中等 | 良好 |

### 优势

1. **更快的优化速度** - 比 onnxsim 快 2-3 倍
2. **更好的精度保持** - 优化后精度损失更小
3. **更高的压缩率** - 平均可减少 10-30% 模型大小
4. **现代化设计** - 支持最新的 ONNX 算子

## 安装

```bash
# 激活虚拟环境
venv\Scripts\activate

# 安装 onnxslim
pip install onnxslim
```

## 功能说明

### UI 选项

在"导出配置"中：
```
☑ 优化模型大小 (使用 onnxslim)
```

- **默认**: 勾选（启用优化）
- **作用**: 减小 ONNX 模型文件大小
- **适用**: 仅对 ONNX 格式有效

### 优化内容

`onnxslim` 会执行以下优化：

1. **算子融合** - 合并连续的算子
2. **常量折叠** - 预计算常量表达式
3. **冗余消除** - 删除无用的节点和张量
4. **形状推断** - 优化动态形状处理
5. **图优化** - 简化计算图结构

### 效果示例

**优化前**:
```
model.onnx - 45.2 MB
```

**优化后**:
```
model.onnx - 32.1 MB (减少 29%)
```

## 使用方法

### 自动优化

1. 勾选"优化模型大小"选项
2. 选择 ONNX 格式
3. 点击"开始转换"
4. 查看日志中的优化报告

### 日志输出示例

```
开始优化 ONNX 模型...
✓ 模型优化完成
  原始大小: 45.23 MB
  优化后: 32.11 MB
  减少: 29.0%
```

## 技术细节

### 优化参数

```python
onnxslim.slim(
    input_model,
    output_model,
    skip_fusion_patterns=False,   # 启用算子融合
    skip_shape_inference=False,   # 启用形状推断
    skip_optimization=False,      # 启用优化
    verbose=False
)
```

### 处理流程

1. 导出原始 ONNX 模型
2. 检测是否勾选"优化模型大小"
3. 如果勾选：
   - 使用 onnxslim 优化模型
   - 报告压缩效果
   - 替换原始文件
4. 验证模型完整性

## 适用场景

### ✅ 推荐使用优化

- 部署到边缘设备（内存受限）
- 需要快速加载模型
- 网络传输模型文件
- 生产环境部署

### ⚠️ 可选关闭优化

- 调试阶段（需要原始结构）
- 模型已经很小
- 需要最快的转换速度

## 兼容性

### 支持的模型

- ✅ 分类模型（MobileNet, EfficientNet, ResNet 等）
- ✅ 检测模型（Faster R-CNN 等）
- ✅ ONNX opset 11-17

### 已测试环境

- Python 3.8+
- ONNX 1.15-1.19
- PyTorch 2.0+

## 故障排查

### 问题 1: onnxslim 未安装

**错误信息**:
```
✗ onnxslim 未安装，跳过优化
  安装命令: pip install onnxslim
```

**解决**:
```bash
pip install onnxslim
```

### 问题 2: 优化失败

**表现**: 使用未优化的模型

**原因**: 模型结构不兼容

**解决**: 取消勾选"优化模型大小"，使用原始模型

### 问题 3: 优化后精度下降

**表现**: 推理结果与原模型不同

**解决**: 
1. 验证原模型是否正确
2. 检查 ONNX opset 版本
3. 取消优化选项
