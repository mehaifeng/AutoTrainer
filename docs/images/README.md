# 项目演示图片

此目录用于存放 AutoTrainer 项目的演示图片和 GIF 动画。

## 需要准备的图片清单

### UI 界面截图

| 文件名 | 说明 | 尺寸建议 |
|--------|------|----------|
| `training_ui.png` | 训练界面截图 | 800x600 或更大 |
| `annotation_ui.png` | 数据标注界面截图 | 800x600 或更大 |
| `validation_ui.png` | 模型验证界面截图 | 800x600 或更大 |
| `export_ui.png` | 模型导出界面截图 | 800x600 或更大 |
| `setup_ui.png` | 环境设置界面截图 | 800x600 或更大 |

### 演示动画 (GIF)

| 文件名 | 说明 | 时长建议 |
|--------|------|----------|
| `quickstart.gif` | 快速开始演示动画 | 10-15 秒 |
| `training_workflow.gif` | 训练流程演示动画 | 15-20 秒 |
| `annotation_workflow.gif` | 标注流程演示动画 | 15-20 秒 |
| `validation_result.gif` | 验证结果演示动画 | 10-15 秒 |

### 其他图片

| 文件名 | 说明 | 尺寸建议 |
|--------|------|----------|
| `logo.png` | 项目 Logo | 512x512 |
| `hero_banner.png` | 首页横幅图片 | 1200x400 |

## 截图工具推荐

### Windows
- **ShareX** - 功能强大的截图录屏工具
- **ScreenToGif** - 专业的 GIF 录制工具

### macOS
- **CleanShot X** - 优秀的截图工具
- **Kap** - 简单易用的 GIF 录制工具

### Linux
- **Kazam** - 屏幕录制工具
- **Peek** - 简单的 GIF 录制工具
